# Практическая работа №3

## 1. Представление числа в байтах

- 1
`01-00-00-00`
- 256
`00-01-00-00`
- 65536
`00-00-01-00`

## 2. Порядок байтов

- Значение `BitConverter.IsLittleEndian` Little-endian: `True`
- Число: `305419896`
- hex-представление: `12-34-56-78`
- Байты: `78-56-34-12`
Так как Little-Endian (True), компьютер записывает байты в память в обратном порядке. Поэтому `12-34-56-78` превратилось в `78-56-34-12`.

## 3. Текст и UTF-8

Текст: ABC
Количество символов: 3
Количество байтов UTF-8: 3
Байты: `41-42-43`

Текст: Привет
Количество символов: 6
Количество байтов UTF-8: 12
Байты: `D0-9F-D1-80-D0-B8-D0-B2-D0-B5-D1-82`

## 4. Английская и русская буква

Английская A: `41`
Русская А:* `D0-90`
